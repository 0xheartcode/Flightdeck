Hosts

One agent per server. It watches containers labelled flightdeck.enable=true.
Run on the new server, then label what it should watch
# 1. start the agent (token from Settings → Agent tokens)
export FD_AGENT_TOKEN=<token>
just agent --hostname "$(hostname)" --control-plane wss://flightdeck.acme.dev/agent

# 2. label a container
docker run -d --label flightdeck.enable=true \
  --label flightdeck.project=storefront \
  --label flightdeck.service=my-api my-image
